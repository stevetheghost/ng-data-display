CDK data table

<app-cdk-data-table> takes the same rows, columns and query as the hand-rolled table, but builds its markup with @angular/cdk/table: each column contributes one definition holding its header, cell and footer, and the row definitions pick the columns they render. Scroll the body — the header and the filter row stay pinned to the top and the totals to the bottom, and those totals cover whatever the current page holds.
